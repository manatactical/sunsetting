# Sunsetting

**Your screens, softer at sundown.**

A free menu-bar app that dims, warms and schedules every display on your Mac.

**[⬇ Download for Mac](https://github.com/manatactical/sunsetting/releases/latest/download/Sunsetting.dmg)**

Free · macOS 15 or later

## Features

- **Brightness per screen.** Set the built-in display and external monitors together, or one at a time. External screens are controlled over DDC/CI.
- **Limits per screen.** Give each display its own minimum and maximum, so every screen stays within the range you want.
- **Night Mode.** One switch caps every display at its minimum brightness.
- **Warmth.** Shift colour toward amber, from 6500K down to 3000K. Brightness stays where you set it.
- **Warm up over time.** Ramp warmth between two times of day, hold it overnight, and return to normal by morning.
- **Brightness keys.** F1 and F2 step all displays together, with the native macOS brightness overlay.
- **Find a screen.** Hover a row to outline that physical display. Right-click to give it a name.
- **Open at Login.** Start Sunsetting automatically when you log in.

## Install

1. Download `Sunsetting.dmg` and drag Sunsetting into Applications.
2. Open it. The icon appears in the menu bar, top right of the screen.
3. Allow Accessibility when asked. It is needed for the F1 and F2 brightness keys.

Sunsetting updates itself when a new version is released.
